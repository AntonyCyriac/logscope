- **Status:** Proposed
- **Date:** 18-08-2026
- **Parent ADR:** [ADR-005 Storage Architecture](ADR-005-Storage-Architecture.md)
- **Release:** `v2.13.0` — Hardening Wave 1
- **Issues:** [#188](https://github.com/AntonyCyriac/logscope/issues/188) [#189](https://github.com/AntonyCyriac/logscope/issues/189) [#195](https://github.com/AntonyCyriac/logscope/issues/195) [#203](https://github.com/AntonyCyriac/logscope/issues/203)

---

## Context

ADR-005 documents incremental append reuse when source file **grows** with matching path. Implementation used **size-only** change detection and swallowed schema open failures. Plugin storage backends could return failure without aborting analyze.

Investigations can appear successful while the index is stale or incomplete — violating the evidence-centric trust model.

**Binding principle:**

> A correctness failure must become explicit rather than silently producing a plausible result.

---

## Decision

### 1. Source integrity ( #188, #189 )

Persist **`source_content_sha256`** (and prefix hash for append) in index meta at `finalize()`.

| Source vs stored | Action |
|------------------|--------|
| Equal size, same content hash | Reuse |
| Equal size, different hash | **Rebuild** |
| Grown, prefix hash matches | Append |
| Grown, prefix hash differs | **Rebuild** |
| Shrunk | Delete index, rebuild |

Incremental reuse **must** evaluate content integrity — not size alone.

### 2. Schema compatibility ( #195 )

| `schema_version` | Behavior |
|------------------|----------|
| > max supported | **Fail closed** — error, do not overwrite DB |
| < current (v1) | **Error** — rebuild required; no silent replace (optional config for explicit rebuild with warning) |
| Current | Open normally |

Propagate open/validation errors through `prepareIndexReuse` — no silent fallback to create-new.

### 3. Plugin storage errors ( #203 )

Plugin `append_line` / `finalize` non-zero → `Error` through `CStorageStoreAdapter` → `HybridIndexWriter` → `AnalysisEngine`. CLI exit non-zero; web analyze returns error response.

### 4. Non-goals

No investigation-domain changes. No desktop/web UX changes in this amendment.

---

## Consequences

- `--reuse-index` may rebuild or fail more often — **correct** behavior
- Same-size log rotation patterns no longer produce silent wrong hits
- Older binaries cannot silently downgrade a newer-schema index file
