## Context

[ADR-008-M14.1](ADR-008-M14.1-Desktop-Investigation-Parity.md) (`v2.11.0`) added Investigation mode with **Timeline** and **Crash** tabs. Story 5/6 **interactive chrome** was explicitly deferred to P2.1. Web ships Related Evidence, link create/remove, Suggested connections accept/dismiss; desktop does not.

`v2.11.0` also documents synchronous Timeline/Crash refresh on the UI thread — a deliberate trade-off closed in P2.1 by wiring existing load workers.

**Mission:** Make desktop investigations as interactive as web investigations — without new domain capabilities.

---

## Decision

### 1. Extend `InvestigationController`

Add delegation methods for Story 5/6 mutations:

- `addEvidenceLink` / `removeEvidenceLink`
- `listCorrelationSuggestions` / `acceptCorrelationSuggestion`

No new types in `apps/common/` beyond existing workspace records.

### 2. Timeline sub-panels

`TimelinePanel` hosts:

- **RelatedEvidencePanel** — list, create, remove links
- **SuggestedConnectionsPanel** — accept/dismiss ephemeral suggestions

Timeline rows show **Related (N)** link badge (`timeline-link-badge`).

### 3. Dismissed suggestions (session state)

Dismissed suggestion IDs live in **`MainWindow` UI session state** — mirror web workspace `correlationStateByInvestigation`, not investigation manifest. Cleared on investigation close.

### 4. Async refresh

`TimelineLoadWorker` and `CrashLoadWorker` become the default load path. Workers re-open `Investigation` by directory path on a background thread; panels update on main thread via signals.

### 5. Viewer navigation

Extend presentation-only `ViewerNavigation` for Related Evidence peer-event jumps — reuse Results/Crash targets from M14.1.

---

## Consequences

### Positive

- Desktop completes Story 5/6 interactive loop using shipped contracts
- v2.11.0 sync refresh limitation closed without domain changes
- Clear separation from #144-B plugin work

### Negative / risks

- `TimelinePanel` grows vertically — acceptable; matches web timeline dock density
- Dismissed IDs not shared across desktop app restarts (same as web session semantics)

### Out of scope (binding)

- `register_crash_analyzer` (#144-B)
- P3 domain architecture charter
- New correlation heuristics or manifest schema changes
