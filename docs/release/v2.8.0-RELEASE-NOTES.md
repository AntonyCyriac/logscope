# v2.8.0 — Discover the Connections (Story 6)

**Type:** Minor (Phase A extension — Story 6)  
**Baseline:** `v2.7.1`  
**ADR:** [ADR-011-M16.0 Investigation Correlation Suggestions](../architecture/decisions/ADR-011-M16.0-Investigation-Correlation-Suggestions.md)

## Summary

Investigations now surface **Suggested connections** — ephemeral correlation proposals when timeline events share exact keys (`request_id`, `trace_id`, `session_id`, `transaction_id`, `correlation_id`) across artifacts. Engineers review the explainability basis, then **accept** (→ persisted `EvidenceLink` via Story 5) or **dismiss** (session-scoped, no manifest write).

## Story Gate demo

```text
Create investigation → Add app.log + syslog → Timeline → select event
  → Suggested connections (basis: key, artifacts, time delta)
  → Accept → RELATED EvidenceLink → Related Evidence → jump
```

Works via **web** (Playwright Story Gate Story 6), **CLI** (`investigation suggestions`), and **REST** (`GET …/correlation-suggestions`, accept/dismiss).

## Added

### Domain (`scope_workspace`)

- `CorrelationEngine` → ephemeral `CorrelationSuggestion[]`
- Exact-key match with ±30s proximity filter; cross-artifact pairs only
- Pair-level dedup: accept suppresses all key variants for the same event pair
- Session-scoped dismiss (not persisted in investigation manifest)

### Web (`logscope-web`)

- `GET /api/v1/investigations/{id}/correlation-suggestions` (optional `eventId`)
- `POST …/correlation-suggestions/{id}/accept` · `POST …/dismiss`
- **Suggested connections** panel on Timeline with explainability basis
- Playwright Story 6 E2E in CI Web Build Smoke

### CLI

- `investigation suggestions list|accept|dismiss <investigationId>`

## Upgrade notes

- No manifest schema change — suggestions are computed on demand
- Dismiss state is per web session; new sessions may recompute dismissed suggestions
- Rebuild and redeploy `logscope`, `logscope-web`, and `logscope-desktop` from tag `v2.8.0`
