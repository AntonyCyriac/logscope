# v2.0.3 — Desktop Regression Hotfix

## Highlights

- Fixes **v2.0.2 desktop bugs**: empty log table after Open/Analyze and AI Ask returning `Matches: 0`
- Adds **headless GUI tests** (`logscope_desktop_tests`) in CI to prevent recurrence

## Fixed

- **Empty log table** after Open when status showed `Analyzed N lines` — table now uses `fetchIndexedLines()` (memory + SQLite index).
- **AI Ask `Matches: 0`** after a successful Open — `agentInvestigate()` reuses the existing analysis model instead of re-analyzing.
- **Ask** updates the center log table with matching rows; empty Ask shows a helpful hint.

## Added

- `logscope_desktop_tests` (Qt Test, `QT_QPA_PLATFORM=offscreen`):
  - Open `sample.log` → 8 table rows
  - Ask `errors` (noop) → 4 rows + `Matches: 4`
  - Persist index enabled → still 8 rows
- Extended `scope_application_tests` for noop AI ask and model reuse
- CI `desktop` job runs desktop GUI tests
- GitHub issue [#86](https://github.com/AntonyCyriac/logscope/issues/86) (closed — tracks v2.0.2 regression)

## Upgrade notes

- **Desktop-only** patch; CLI unchanged.
- Replace `logscope-desktop` binary or download new release artifacts.
