# v2.7.0 — Connect the Evidence (Story 5)

**Type:** Minor (Phase A — Story 5, completes Phase A)  
**Baseline:** `v2.6.2`  
**ADR:** [ADR-010-M15.9 Investigation Evidence Links](../architecture/decisions/ADR-010-M15.9-Investigation-Evidence-Links.md)

## Summary

Investigations now support **manual Evidence Links** — investigator-authored relationships between timeline events (`PRECEDES`, `FOLLOWS`, `SUPPORTS`, `RELATED`). Links persist in the investigation manifest (`schemaVersion: 2`, `evidenceLinks[]`), surface in the web **Related Evidence** panel and timeline **Connections** badges, and are available via REST and CLI.

## Story Gate demo

```text
Create investigation → Add app.log + syslog.log + pstack
  → Analyze → Timeline → select event → Add connection
  → Badge on timeline → Related Evidence row → jump to peer event
```

Works via **web** (Playwright Story Gate Story 5), **CLI** (`investigation links`), and **REST** (`GET/POST/DELETE …/evidence-links`).

## Added

### Domain (`scope_workspace`)

- `EvidenceLink`, `EvidenceLinkRecord`, manifest `schemaVersion: 2` with `evidenceLinks[]`
- Immutable links (create + remove; no PUT/PATCH)
- Stale link status when endpoint event ids are absent from timeline projection
- Duplicate directed triple → **409** `DUPLICATE_EVIDENCE_LINK`

### Web (`logscope-web`)

- `GET/POST/DELETE /api/v1/investigations/{id}/evidence-links`
- Related Evidence panel, link create form, timeline connection badges
- Playwright Story 5 E2E in CI Web Build Smoke

### CLI

- `investigation links list|add|remove <investigationId>`
