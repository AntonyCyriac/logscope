# v1.5.1 — M13 AI Assistant

## Highlights

- Pluggable AI providers (`noop` default, `http` for OpenAI-compatible APIs)
- `logscope agent investigate` with `--ask`, `--summarize`, and `--hints`
- Natural-language → validated filter DSL translation
- Investigation summaries and analytics-driven anomaly hints
- Offline-first: CI and default config use `noop` (no network)

## Added

- `scope_ai` module and `AiInvestigationAssistant` orchestrator
- `NoOpAiProvider` for deterministic offline behaviour
- `HttpAiProvider` with cpp-httplib chat completions client
- Config keys `ai.*` and environment variable `LOGSCOPE_AI_API_KEY`
- `samples/ai-noop.properties` for e2e testing

## Changed

- `config validate` checks `ai.*` configuration
- CLI help documents `agent investigate`

## Documentation

- ADR-007 AI Integration (Accepted)
- M13 planning and v1.5.1 acceptance scenarios
- CLI Reference and User Manual AI workflow sections

## Upgrade notes

- No breaking changes for default configuration (`ai.enabled=false`)
- Enable HTTP AI with `ai.provider=http`, endpoint, model, and API key env var

## Known limitations

- PRD-001 full agent roster not included (future milestones)
- HTTP provider quality depends on external LLM; host validates DSL syntax only

## Test baseline

513 automated tests (including 42 `scope_ai_tests` cases)
