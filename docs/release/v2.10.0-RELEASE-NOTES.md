# v2.10.0 — P1.1 alternate pstack dialects (#144)

**Type:** Minor (P1.1 — Story 4 enhancement)  
**Baseline:** `v2.9.1`  
**ADR:** [ADR-009-M15.8 Crash Analysis](../architecture/decisions/ADR-009-M15.8-Crash-Analysis.md) (TID dialect amendment)

## Summary

Ships **P1.1** — native support for alternate **TID-style** pstack dumps that previously returned `No threads parsed from pstack` ([#144](https://github.com/AntonyCyriac/logscope/issues/144)). GDB-style pstack output is unchanged.

## Added

### [#144](https://github.com/AntonyCyriac/logscope/issues/144) — TID pstack dialect

- Dialect sniffing via `TID n:` thread headers (`PID n - process` file header)
- Frame parsing: `symbol - /path/lib.so` and ` - 1 ` variant tokens
- Indented source location lines (`    /build/src/file.c:line:col`)
- **`__restore_rt`** / **`__kernel_rt_sigreturn`** treated as signal-handler boundary (equivalent to GDB `<signal handler called>` / #134)
- Reuses existing fault-thread scoring (#129, #134)
- Report metadata: `pstackDialect` (`gdb` | `tid`); analyzer version `pstack-v2`
