# v2.0.1 — Desktop Release Packaging

## Highlights

- **`logscope-desktop` on Windows and macOS** — release archives with bundled Qt runtime
- **GitHub Actions Node.js 24** — updated checkout, artifact, and release action versions

## Added

- `logscope-desktop-windows-amd64.zip` — MSVC build with `windeployqt`
- `logscope-desktop-macos-amd64.tar.gz` — Apple Silicon build with `macdeployqt`

## Changed

- Release workflow desktop matrix (Linux, Windows, macOS)
- CI/release workflows: `actions/checkout@v7`, `upload-artifact@v7`, `download-artifact@v7`, `softprops/action-gh-release@v3`

## Upgrade notes

- No code changes from `v2.0.0`; use this release if you need pre-built desktop binaries on Windows or macOS.
- Linux desktop artifact unchanged (`logscope-desktop-linux-amd64.tar.gz`).
