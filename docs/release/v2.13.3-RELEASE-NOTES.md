# v2.13.3 — Run Comparison (Hardening Wave 4)

**Type:** Patch (trust / correctness — contrast between runs)  
**Baseline:** `v2.13.2`  
**ADR:** [ADR-014 Evidence Run Comparison](../architecture/decisions/ADR-014-Evidence-Run-Comparison.md)

## Summary

`v2.13.3` adds **run comparison**: baseline vs candidate contrast on normalized error signatures, aligned on Wave 3 file/instance identity. Absence in the candidate is first-class evidence (`onlyInBaseline`); incomparable runs fail closed (exit **2**).

**Run Comparison Gate (Wave 4, failure-shape step 3):**

```text
Align on instanceKey + relativePath — not stream line numbers
onlyInBaseline / onlyInCandidate / countDeltas on comparable runs
Incomparable → comparable:false, exit 2
```

**Binding principle:** an empty diff must not imply equality when runs cannot be aligned.

## Added

### CLI — `logscope compare`

```bash
logscope compare <baseline> <candidate> [--format text|json] [--no-recursive]
```

- **Baseline** and **candidate** use the same discovery + analysis pipeline as `analyze` (ADR-013)
- **JSON** output under `data.comparison`: `comparable`, `complete`, `alignment`, `onlyInBaseline`, `onlyInCandidate`, `countDeltas`, `warnings`
- **Text** output summarizes signature additions, removals, and count deltas
- **Single-file** roots pair implicitly when both paths are files
- **Multi-instance** bundles align on `instanceKey` and `sourceFileRelative`

### Core — `core/compare`

- `RunSnapshot` — error signature map from `AnalysisModel`
- `RunAligner` — instance + file alignment (rotation-aware when `rotationGroupId` set)
- `RunDiffer` — signature diff and count deltas
- `compareModels()` orchestration with explicit `IncomparableReason` codes

### Exit codes (compare)

| Code | Meaning |
|------|---------|
| `0` | Comparable comparison produced |
| `1` | Invalid arguments / unsupported path |
| `2` | Incomparable or indeterminate (e.g. `NO_INSTANCE_OVERLAP`, `BASELINE_INDETERMINATE`) |

## Changed

- Investigators and CI pipelines can contrast two runs without manual mental diff or external tools
- Partial ingest on either side may set `complete: false` with `COMPARISON_BOUNDED` warning while still comparable
