# v2.1.0 — M15 Web Platform

## Highlights

- **`logscope-web`** — local REST API + browser workbench over shared `ApplicationService`
- **Browser MVP** — upload, analyze, investigate, export, extensions, AI ask (vanilla SPA at `/`)
- **CLI parity** — analyze, investigate, analytics, and agent investigate match `--format json` on `samples/sample.log`
- **Security baseline** — loopback bind, optional API key, path traversal guards, upload size limits

- CI **`web`** job (Ubuntu, `LOGSCOPE_WEB=ON`)
- **GitHub Release** — `logscope-web-v2.1.0-{linux,windows,macos}-amd64` archives (binary + SPA + `samples`)

## Changed

## Upgrade notes

**From release archive** (extract, run from that directory):

```bash
./logscope-web
# Open http://127.0.0.1:8080/
```

**From source:**

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DLOGSCOPE_WEB=ON
cmake --build build --target logscope-web
./build/apps/web/logscope-web
```

- Default bind: `127.0.0.1:8080`. Do not expose on untrusted networks without `web.api_key`.
- `web.allow_server_paths` defaults **false**; use multipart upload from browser.
