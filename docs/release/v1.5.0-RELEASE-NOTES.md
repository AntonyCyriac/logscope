# v1.5.0 — M12 Dynamic Plugins

## Highlights

- Runtime `.so`/`.dll` plugin loading with C ABI vtables
- Parser, report, search, and storage provider plugins
- Plugin SDK headers and CMake `logscope_add_plugin` helper
- Sample plugins and cross-platform CI matrix

## Added

- `PluginLoader`, `ParserRegistry`, `SearchProviderRegistry`, `StorageBackendRegistry`
- Config keys `plugins.enabled`, `plugins.paths`, `LOGSCOPE_PLUGIN_PATH`
- `analysis.plugin_format`, `investigation.search_provider`, `storage.backend=plugin:<id>`
- `examples/plugins/sample_*` reference implementations
- `scope_plugin_tests` integration suite

## Changed

- `ExtensionManager` supports dynamic extensions
- `extensions list` / `extensions describe` show loaded plugin metadata
- All analysis/investigation CLI paths load configured plugins

## Documentation

- PLUGIN_DEVELOPMENT_GUIDE v2.0.0
- ADR-006 Plugin Loading (Accepted)
- M12 planning and acceptance scenarios

## Upgrade notes

- No breaking CLI changes for default configuration
- Enable plugins with `plugins.enabled=true` and `plugins.paths=/path/to/plugins`

## Known limitations

- No marketplace, signing, or sandbox (see ADR-006 threat model)
- M13 AI Assistant not included

## Test baseline

462 automated tests (including 10 plugin loader/provider cases)
