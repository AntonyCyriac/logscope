# v2.2.1 — M15.4 Thin Auth

## Highlights

- **Session idle TTL** — configurable `web.session_ttl_seconds`; evicted sessions return `401 SESSION_EXPIRED`
- **Upload temp cleanup** — superseded staged uploads removed on replace, evict, and shutdown
- **Health API key policy** — optional `web.health_requires_api_key` (default: health open per ADR-009)
- **Bind warning** — startup log when non-loopback bind without API key
- **Operator guide** — [Securing logscope-web](../handbook/SECURING_LOGSCOPE_WEB.md)

## Added

- `SessionStore` idle eviction + `web.max_sessions` capacity eviction
- `session_resource_cleanup` — tail stop + temp file delete on evict
- Config keys: `web.session_ttl_seconds`, `web.max_sessions`, `web.health_requires_api_key`
- ADR amendment: [ADR-009-M15.4-Thin-Auth](../architecture/decisions/ADR-009-M15.4-Thin-Auth.md)
- **57** web-labelled tests green (unit + integration + parity)

## Changed

- Version **2.2.1** — PATCH hardening release (no new REST routes)
- `replaceStagedUpload` / open/load paths clean prior upload temps

## Upgrade notes

**From v2.2.0:** Defaults preserve prior behavior (`session_ttl_seconds=0`, `health_requires_api_key=false`). No migration required.

```bash
./logscope-web --config samples/web.properties
```

Recommended for shared hosts:

```properties
web.api_key=<long-random-secret>
web.session_ttl_seconds=3600
# web.max_sessions=50
```

See [Securing logscope-web](../handbook/SECURING_LOGSCOPE_WEB.md) and [Configuration Guide §11](../handbook/CONFIGURATION_GUIDE.md#11-web-platform-logscope-web).
