# v2.12.0 — Desktop Evidence & Suggestions (P2.1)

**Type:** Minor (P2.1 — desktop Story 5/6 interactive parity)  
**Baseline:** `v2.11.0`  
**ADR:** [ADR-008-M14.2 Desktop Evidence & Suggestions](../architecture/decisions/ADR-008-M14.2-Desktop-Evidence-Suggestions.md)

## Summary

Desktop (`logscope-desktop`) gains the **Story 5/6 interactive chrome** that shipped on web in `v2.7.0` / `v2.8.0`: **Related Evidence**, evidence link create/remove, **Suggested connections** accept/dismiss, and **Related (N)** timeline badges — all via existing `workspace::Investigation` contracts through an extended `InvestigationController`. **Async** Timeline/Crash loading closes the v2.11.0 synchronous UI-thread refresh limitation.

**Story Gate paths:**

```text
Story 5: link → Related (N) badge → jump → remove
Story 6: accept suggestion → link; dismiss → no link
P2 regression: crash.summary → Crash → fault-thread jump
```

## Added

### InvestigationController (Story 5/6)

- `addEvidenceLink` / `removeEvidenceLink` / `listEvidenceLinks`
- `listCorrelationSuggestions` / `acceptCorrelationSuggestion`

### Desktop Timeline chrome

- **RelatedEvidencePanel** — list, create, remove links; jump to peer log line or crash
- **SuggestedConnectionsPanel** — accept/dismiss ephemeral suggestions (Story 6)
- **Connections** column with **Related (N)** badge on linked rows
- Session-local dismissed suggestion IDs in `MainWindow` (cleared on investigation close)

### Async refresh

- `TimelineLoadWorker` / `CrashLoadWorker` on background threads (default load path)
- Removes v2.11.0 UI-thread blocking on tab activation

### Tests

- `logscope_desktop_parity_test` — Story 5, Story 6, and P2 regression (7 scenarios)
- `InvestigationControllerTest` — evidence link CRUD + suggestion accept

## Upgrade notes

- Rebuild or install `logscope-desktop` from tag `v2.12.0`
- No manifest, REST, or CLI JSON shape changes
- Dismissed suggestions are session-local (same semantics as web workspace correlation state)
