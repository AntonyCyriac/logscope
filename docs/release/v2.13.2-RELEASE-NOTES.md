# v2.13.2 — Ingestion Integrity (Hardening Wave 3)

**Type:** Patch (trust / correctness — evidence discovery and attribution)  
**Baseline:** `v2.13.1`  
**ADR:** [ADR-013 Evidence Ingestion Integrity](../architecture/decisions/ADR-013-Evidence-Ingestion-Integrity.md)

## Summary

`v2.13.2` restores **ingest trust**: LogScope must not report success when most discovered evidence never entered analysis. Every analyzed line is attributable to a discovered file; every discovered candidate has an explicit disposition.

**Ingestion Integrity Gate (Wave 3, steps 1–2):**

```text
Discovery census before parse — skips, rotation, instances
File identity on every indexed line (schema v3)
Discovered ≠ analyzed (exit 0 does not imply discovery completeness)
```

**Binding principle:** silent omission at discovery is the least detectable trust failure.

## Added

### Discovery and census

- Recursive, content-informed directory discovery (not `.log`-suffix only)
- `DiscoveryCensus` with per-candidate disposition: `ANALYZED` | `SKIPPED` | `UNSUPPORTED` | `FAILED`
- Skip reasons (`BINARY_CONTENT`, `UNREADABLE`, etc.) surfaced in census
- Rotation groups: full history ingested oldest → newest, live file last
- Instance grouping (`instances[]`) for multi-instance bundles

### File identity

- Per-line attribution: `sourceFileRelative`, `fileLineNumber`, stream `lineNumber`
- Persisted index **schema v3** stores `source_file` + `file_line_number` (v1/v2 indexes require rebuild)

### Reporting and CLI

- JSON `sourceMetadata.discovery` and `sourceMetadata.analysis` on `logscope analyze --format json`
- `analysis.complete: false` when skips or unknown dialect warnings occurred
- `logscope analyze --no-recursive` to limit directory traversal depth
- Exit **2** (`Indeterminate`) when candidates exist but none could be ingested
- Archive paths (`.tar`, `.tar.gz`, `.zip`) fail with extract guidance (exit **1**)

## Changed

- Directory ingest is **recursive** and **content-informed** by default
- Some paths that previously exited **0** with no useful analysis now exit **2** when all candidates are skipped (intended correction)

## Upgrade notes

- Rebuild or install CLI/web/desktop from tag `v2.13.2`
- **Breaking behavior (intentional):** all-skipped directories return exit code **2**, not **0**
- **Index rebuild:** existing v2 SQLite indexes rebuild on next analyze (schema v3)
- No investigation-domain or desktop/web UX changes in this wave
