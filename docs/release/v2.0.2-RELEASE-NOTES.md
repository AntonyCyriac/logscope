# v2.0.2 — Desktop CLI Parity Polish (M14.12)

## Highlights

- **Desktop GUI parity** with common CLI investigation workflows (M14.12 Phase A + B)
- **Export report section picker** — choose format and sections before export
- **Index storage toggles** — Persist index / Reuse index on the Analyze toolbar
- **Run Statistics dialog** — full `--stats` output after Analyze

## Added

- **Export Report dialog** — format combo + section checkboxes; defaults from `report.sections` config (GAP.2)
- **Persist index / Reuse index** toolbar checkboxes on Analyze (GAP.3)
- **View → Run Statistics…** — `RunStatsDialog` mirrors CLI `printRunStats()` (GAP.7)
- **Investigate time range** — From/To fields wired to `InvestigationCriteria.timeRange` (GAP.1, Phase A)
- **Config validate on load** — `ApplicationService::validateConfiguration()` after File → Load Configuration… (GAP.5)
- **Extension describe panel** — metadata from `describeExtension()` when selecting an extension (GAP.6)

- Planning docs: M14.12 Phase A + B complete; Phase C (config editor, session filters) remains
