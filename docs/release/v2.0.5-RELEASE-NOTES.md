# v2.0.5 — CI / build hotfix (v2.0.4 follow-up)

## Highlights

- Fixes **Linux desktop build** broken in `v2.0.4` (`QDialogButtonBox` incomplete type)
- Fixes **CI test** `AnalyzeDirectoryProducesCombinedReport` after `samples/large-app.log` skewed directory totals
- **Versioned release artifacts** — archives include tag in filename (e.g. `logscope-v2.0.5-linux-amd64.tar.gz`)

## Fixed

- Desktop: `#include <QDialogButtonBox>` in `configuration_editor_dialog.cpp` (Linux compile error).
- Desktop: `[[nodiscard]]` on `openLogFile()` in session load paths.
- Test: directory analyze e2e uses isolated temp logs instead of entire `samples/` directory.

## Upgrade notes

- **Recommended** for anyone who downloaded `v2.0.4` desktop Linux builds or relies on CI-green binaries.
- CLI behavior unchanged; desktop Linux package was not buildable from `v2.0.4` tag on some runners.
