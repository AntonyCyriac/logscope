# v2.0.0 — M14 Desktop Application

## Highlights

- Qt6 Widgets desktop app (`logscope-desktop`) — investigation workbench with CLI parity
- Shared `ApplicationService` orchestration for CLI and GUI
- Live tail (`TailingFileLogSource`) with desktop toggle
- Filter bar, analytics tabs, report export, sessions, extensions, AI assistant panel
- Dark/light themes

## Added

- `scope_application` library (`apps/common/`)
- `logscope-desktop` target (`apps/desktop/`)
- Source live tail: `OpenOptions::follow`, `TailingFileLogSource`
- ADR-008 Desktop Qt Presentation
- M14 planning and acceptance scenarios
- CI desktop build smoke (Ubuntu + Qt6)

## Changed

- `LogAnalyzer` delegates to `ApplicationService`
- Version **2.0.0** — major presentation-layer release (M14)

## Upgrade notes

- Build desktop: `cmake -DLOGSCOPE_DESKTOP=ON` (requires Qt6 Widgets).
- CLI unchanged for default workflows; install `logscope-desktop` alongside `logscope`.

## Known limitations

- M15 Web UI not included (follow-on `v2.0.x` / `v2.1.0`).
- Windows/macOS desktop archives bundle Qt runtime via `windeployqt` / `macdeployqt`; Linux desktop expects system Qt6 Widgets at runtime unless built locally with a bundled layout.

## Test baseline

**520+** automated tests including `scope_application_tests` and `tailing_file_log_source_test`.
